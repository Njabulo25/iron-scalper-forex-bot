Start Iron Scalper

One launcher for the dashboard and trading engine

  1. 1Install Python 3.12 and MetaTrader 5 for Windows, then sign in to MT5.
  2. 2Double-click run.bat. The first run creates the Python environment and installs dependencies.
  3. 3Open http://127.0.0.1:5000 and sign in to the terminal.
  4. 4Check the account, symbol and risk settings, then choose Start engine.
  5. 5If MT5 reports Terminal: Authorization failed, verify the trading account number and exact broker server (not the MQL5 Community login). In Tools → Options → Expert Advisors, clear Disable automated trading via external Python API only if you intend to let Python place orders. Use IRON_SCALPER_MT5_LOGIN, IRON_SCALPER_MT5_SERVER and, if needed, IRON_SCALPER_MT5_PATH to select the saved account and terminal.

The dashboard stays stopped until you start the engine. Trade history and model results are read from data/iron_scalper.db.
