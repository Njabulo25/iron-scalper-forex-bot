Running this terminal elsewhere

Same engine, same database, same page

  1. 1Copy the Iron Scalper folder to the target machine.
  2. 2Install Python 3.10+ and a signed-in MetaTrader 5 terminal.
  3. 3pip install -r requirements.txt
  4. 4python src/engine/web_dashboard.py
  5. 5Open http://localhost:5000 and sign in.
  6. 6Log into the MT5 demo account, then start the engine here.

The database lives in data/iron_scalper.db. Copy it with the folder to keep the trade record.
